# SX Klogg

这是基于 [klogg](https://github.com/variar/klogg) 定制的日志查看工具分支。

这个分支不重复介绍 klogg 原项目本身。这里重点记录本分支针对日常检查 log 的工作流做了哪些调整，以及最终界面效果。

![SX Klogg demo](website/static/screenshots/sx_klogg_demo.png)

## 改造目标

原始 klogg 已经具备高性能大文件浏览、搜索、过滤、高亮能力，但过滤器和高亮配置比较分散，过滤后的 log 与完整 log 的查看方式也不够贴近日常排查习惯。

本分支的目标是让 klogg 更接近 TextAnalysisTool.NET 的使用方式：

- 主窗口只显示一种主体内容：`Filtered Log` 或 `Full Log`。
- 过滤后的 log 作为优先视图，用于快速定位问题点。
- 完整 log 作为同一主窗口里的另一面，用于回看上下文和避免漏掉信息。
- 底部集中展示、编辑、启用、禁用过滤器和高亮规则。
- 高亮规则和过滤器规则统一维护，避免一边加过滤器、一边再单独配置高亮。

## 主要改动

### Filtered Log / Full Log 切换

主窗口增加 `Filtered Log` / `Full Log` 切换按钮。

- `Filtered Log`：显示由底部过滤器组合得到的过滤结果。
- `Full Log`：显示完整原始 log。
- 两个视图不同时占用主体空间，避免窗口被拆得过碎。
- 支持 `Ctrl+H` 快捷键在两个视图之间切换。

### 底部过滤器面板

窗口底部新增过滤器管理面板，用于集中维护当前使用的过滤器。

每条过滤器支持：

- 启用 / 禁用
- 过滤文本
- 前景色
- 背景色
- 命中次数
- 是否使用正则表达式
- 是否大小写敏感
- 是否全词匹配
- 关键字高亮 / 全行高亮
- 只读序号和可编辑的优先级

底部面板可以通过拖动分隔条调整高度，扩大后过滤器列表会真正获得更多显示空间。

- `Ctrl+J` 隐藏或显示整个底部控制区域，重新显示时恢复之前的高度；隐藏不停止过滤或定时重载。
- `Ctrl+=` 或 `Ctrl++` 放大底部控制区域字体，`Ctrl+-` 缩小字体，使用退格键旁的主键盘按键。
- 字体缩放影响按钮、表头、规则表和下拉框，不改变日志正文字体。

### 每秒重载并滚动到底部

勾选底部的 `Reload every second` 后，每隔 1 秒重新载入当前日志文件。

- 重新载入后自动滚动到底部，不需要操作鼠标。
- 启用过滤器时，重新计算过滤结果，并在搜索完成后滚动到结果末尾。
- 没有启用过滤条件时，显示完整日志并滚动到末尾。
- 保留当前过滤器配置和仍在文件范围内的行标记。
- 文件加载或搜索尚未完成时，跳过当次定时重载，避免反复中断大文件处理。
- 取消勾选后停止定时重载，不再强制滚动到底部；已开始的载入会正常结束。

### 自动应用过滤器

过滤器发生变化后会自动应用，不再需要每次手动点击搜索框或放大镜。

会自动触发过滤的操作包括：

- 勾选 / 取消勾选过滤器
- 新增过滤器
- 删除过滤器
- 修改过滤器文本或选项
- `Enable All`
- `Disable All`
- `Remove All`
- 上移 / 下移过滤器

`Apply` 按钮仍然保留，用于需要手动重新应用时显式触发。

### 高亮与过滤器统一

每个高亮规则都可以同步作为过滤器使用。

过滤表达式会按启用的过滤器自动组合，例如：

```text
camera|sv_element|first_pixel|ret=
```

不再展示或要求用户手动维护顶部搜索框中的组合表达式。

### 过滤器保存和加载

支持将当前过滤器配置保存到文件，并从文件重新加载。

用途：

- 保存项目常用默认过滤器。
- 系统异常关闭后，通过加载文件恢复过滤器。
- 不同项目之间切换过滤器配置。

### 过滤器顺序调整

支持上移、下移过滤器。

`Use` 前的 `No.` 列按当前排列自动显示序号，移动、新增或删除规则后重新编号。

颜色覆盖分两级判断：

1. 先比较 `Priority`，数值越大，优先级越高。
2. 优先级相同时，序号越小，优先级越高。

上移、下移只改变序号，不修改规则的优先级，因此只能改变同优先级规则之间的覆盖关系。
关键词规则仅覆盖命中的文字，整行规则覆盖整行；重叠部分遵循相同的优先级判断。
选择文本和临时搜索高亮仍沿用原来的显示行为。

优先级与规则一起保存和加载。旧配置中没有优先级的规则默认为 `0`，保持原来靠前规则优先的效果。

### 横向滚动

支持 `Shift + 鼠标滚轮` 横向滚动。

横向滚动速度已调低，避免轻微滚动就移动过远。

## 当前推荐用法

1. 打开 log 文件。
2. 在底部过滤器面板中添加关注的关键字。
3. 为不同关键字设置前景色、背景色和高亮方式。
4. 默认查看 `Filtered Log` 快速定位问题。
5. 需要完整上下文时按 `Ctrl+H` 切到 `Full Log`。
6. 将常用过滤器保存为文件，后续项目中直接加载复用。
